# Expense and Maintenance Update QA

The Expenses workspace now offers All, By Trip, By Truck, By Trailer, and By Type reports. The entry dialog renders every expense as one wide horizontal row at desktop width, with trip, date, persisted/custom type, description, amount, attachment, and row removal controls aligned across the same line. No test expense data was created during visual QA.

## Maintenance

The new Maintenance navigation item loads a fleet-care dashboard with total, truck, trailer, and upcoming-service metrics. The Add Maintenance form includes truck selection, truck/trailer asset selection, service date, standard or custom maintenance type, amount, workshop, odometer, next-service date, description, and multiple service-document attachments. The UI clearly states that each saved cost is automatically linked into Expenses. No maintenance test record was created during QA.
